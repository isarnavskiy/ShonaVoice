# Офлайн-модели Shona Voice

В сборке 1.0.0 текст, запись с микрофона и синтез речи обрабатываются на телефоне. При первом запуске приложение распаковывает из APK 13 файлов моделей и словарей (2,09 ГБ) и проверяет их по SHA-256. Для перевода на шона дополнительно создаётся локальный декодер размером около 476 МБ. Оба голоса входят в APK.

| Функция | Модель и особенности | Источники |
| --- | --- | --- |
| Перевод между русским и шона | NLLB-200 distilled 600M, графы INT8 и токенизатор SentencePiece. При переводе на шона декодер сравнивает три продолжения, при переводе на русский выбирает одно. До 2000 символов за запрос. | [Meta AI](https://huggingface.co/facebook/nllb-200-distilled-600M) · [ONNX-экспорт Xenova](https://huggingface.co/Xenova/nllb-200-distilled-600M/tree/261c31d1a5732c67cdd16d80e8d6088507c7ccea) |
| Распознавание русской речи и шона | MMS-1B-all, общие веса INT8 и отдельный языковой адаптер для каждого языка. Запись до 12 секунд приводится к моно, 16 кГц. При распознавании шона дополнительно учитываются частоты сочетаний букв. | [Meta AI](https://huggingface.co/facebook/mms-1b-all) · [ONNX-экспорт OpenVoiceOS](https://huggingface.co/OpenVoiceOS/mms-1b-all-onnx/tree/6007394849e9b73c001ed688be99f5b6ad3f464c) |
| Озвучивание шона | MMS-TTS-SNA, 16 кГц. Для Android свёрточные слои с постоянными весами квантованы в INT8. Для озвучивания чисел их нужно записать словами. | [Meta AI](https://huggingface.co/facebook/mms-tts-sna) · [ONNX-экспорт Will Wade](https://huggingface.co/willwade/mms-tts-multilingual-models-onnx/tree/4f49fc254f11ddb0e35fbf25b6e48b04463a6779/sna) |
| Озвучивание русского | MMS-TTS-RUS, 16 кГц. Приложение подготавливает текст и использует исходный ONNX-граф и словарь символов, преобразованный в JSON. | [Meta AI](https://huggingface.co/facebook/mms-tts-rus) · [ONNX-экспорт Will Wade](https://huggingface.co/willwade/mms-tts-multilingual-models-onnx/tree/4f49fc254f11ddb0e35fbf25b6e48b04463a6779/rus) |

## Проверка качества

Код перевода и распознавания из сборки проверен на Linux x86-64 с ONNX Runtime 1.22.0. Для распознавания использованы записи носителей из тестовой выборки FLEURS. Длительность в примерах синтеза относится к полученной аудиозаписи.

| Проверка | Наблюдение |
| --- | --- |
| Перевод в обе стороны | Фраза «Встречу перенесли на пятницу. Адрес не изменился.» дала «Musangano wacho wakachinjirwa kusvika musi weChishanu. Kero yacho haina kuchinja.». Обратный перевод — «В пятницу встреча была перенесена. Адрес не изменился.». Возникло смысловое различие между датой встречи и датой её переноса. |
| Русская запись, FLEURS № 1926 | В отрывке длиной 8,64 с совпали 9 из 10 слов. В имени «Аристотеля» модель заменила одну гласную. |
| Запись шона, FLEURS № 1796 | В отрывке длиной 10,56 с совпали 4 из 11 слов в соответствующих позициях. В частности, «masandbar» распознано как «masanba». |
| Оба встроенных голоса | Русская фраза о переносе встречи дала 3,95 с звука, её перевод на шона — 4,91 с. Повторное распознавание этих записей дало текст на соответствующих языках с ошибками в отдельных словах. |

Эти примеры показывают, какие ошибки возможны в коротком диалоге. Даты, имена и числа стоит сверять с собеседником. Для оценки точности в конкретной сфере нужна отдельная выборка разговоров и проверка носителями обоих языков.

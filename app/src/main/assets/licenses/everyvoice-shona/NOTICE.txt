Changes for Shona Voice: exported FastSpeech2 and the HiFi-GAN generator to single-speaker FP32 ONNX (opset 17) for offline inference. Training and discriminator weights were removed. Dynamic single-request attention and duration expansion were expressed using ONNX-compatible tensor operations. The voice uses SPEAKER_00_Shona and 22,050 Hz output. The application token table is derived from the checkpoint's character and punctuation configuration. The upstream model does not endorse this application.

The conversion uses EveryVoice 0.5.0 and torchaudio 2.6.0. Their software licenses and notices are provided next to this file. The model weights have their own CC BY-SA 4.0 license, independent of the software licenses.
